# 📊 Credit Risk Analysis Dashboard

## 📌 Project Overview

The **Credit Risk Analysis Dashboard** is an interactive Power BI project designed to analyze loan applicant data and identify key factors influencing credit risk and loan defaults. The dashboard provides meaningful business insights through dynamic visualizations and KPI tracking, enabling better credit assessment and data-driven decision-making.

---

## 🎯 Objectives

- Analyze loan default trends.
- Identify high-risk customer segments.
- Evaluate the impact of loan grade, employment, and home ownership.
- Build an interactive dashboard for business users.
- Support data-driven lending decisions.

---

## 🛠️ Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Microsoft Excel

---

## 📈 Dashboard Features

- Loan Default Analysis
- Credit Risk Assessment
- Loan Grade Distribution
- Interest Rate Analysis
- Employment Length Analysis
- Home Ownership Analysis
- Loan Purpose Analysis
- KPI Cards
- Interactive Filters & Slicers

---

## 💡 Key Insights

- Higher-risk loan grades show significantly higher default rates.
- Borrowers with shorter employment history have a greater probability of default.
- Interest rates generally increase with borrower risk.
- Certain loan purposes exhibit higher default tendencies than others.
- Interactive filters enable detailed analysis across multiple customer segments.
